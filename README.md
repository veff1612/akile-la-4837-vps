## 先确认你买的是哪一种“4837”

AS4837 是中国联通骨干网的自治系统编号，走这条线的美国机器，回国那一段从联通的 CUVIP 出口走。行业里被统称为“4837 优化”的机器，其实至少有三种不同的回程口径：

1. 三网回程全部强制走 4837，去程各自直连；
2. 去程电信、联通、移动各走自己的骨干直连机房，回程统一从 CUVIP 4837 出来；
3. 电信走 163、联通走 4837、移动走 CMI，三家各回各家。

这三种在商家页面上都写成“4837 线路”，晚高峰的实际表现并不一样。第一种对联通用户最友好，第三种更接近“国际方向择优选路”的做法，电信用户体验会好一些但已经不算纯 4837 了。下单前值得做的一件事，是让商家提供去程和回程的路由测试图，或者拿测试 IP 自己跑一遍 traceroute，看清楚回程到底从哪个 AS 出来。宣传语里的“美国直连”不能当路由证据用，绕日本、韩国甚至欧洲回国的机器也会这么写。

Akile 这边还有一个容易踩的点：官网美国区的节点下拉里，4837 相关有两个名字，LAX4837 和 LAX4837ISP。带 ISP 后缀的是单独一条产品线，第三方测评把这组机器描述成双 ISP 接入加原生静态 IP，电信方向走 CUVIP 4837 回程。两条线的价格和 IP 属性不一样，别看“4837”三个字就往购物车里放。
